# Abra NIP Dashboard — SBI RHU Encoder FAQs

Version: v5.19.2

## 1. What is the easiest way to know whether I need Follow-up or Revision?

If the learner was vaccinated on a **new date**, use a **Follow-up Activity**. If you are correcting something already saved for the **same date**, use **Revision / Correction**.

## 2. Is the System Learner ID the same as the DepEd LRN?

No. It is generated by the Abra NIP Dashboard and is used to match the same learner across activity dates and revisions.

## 3. Do I type the System Learner ID?

No. Do not create or edit it.

## 4. Student A received MR yesterday and Td today. What do I encode?

Yesterday: MR = Given, Td = Not Given.  
Today: MR = Not Given, Td = Given.  
Use the same System Learner ID on both dates.

## 5. Why can't I copy yesterday's MR = Given into today's row?

Because the dashboard would count another MR dose on today's Activity Date.

## 6. How do I prepare a follow-up file?

Use **Create Follow-up Line List** in Step 1. Upload the previous v5.19+ workbook and download the generated follow-up workbook. It keeps the learner IDs and clears the Activity Date/outcome fields.

## 7. What happens to learners who did not return for follow-up?

Leave their generated follow-up row untouched. Blank identity-only rows are ignored.

## 8. Can the same learner appear on several activity dates?

Yes. That is expected for follow-up vaccination. The System Learner ID stays the same.

## 9. What is an exact duplicate?

The same **Activity Date + School + Grade + System Learner ID** cannot be saved as another separate activity record.

## 10. How do I correct a vaccine status or lot/batch number?

Keep the same Activity Date and System Learner ID, correct the field, and upload the **complete Activity Date + School + Grade group** through Step 1.

## 11. Why must I upload the complete group for a revision?

Because the dashboard treats each included Activity Date + School + Grade group as the complete current list. Missing saved learners in that group are shown as removals.

## 12. What do Added, Modified, Removed, and Unchanged mean?

**Added** creates a new activity record. **Modified** updates an existing record. **Removed** makes a previously saved record inactive because it is missing from the complete revised group. **Unchanged** already matches what is saved.

## 13. What if I see many unexpected Removed records?

Do not confirm the import. Check whether you uploaded only part of an existing Activity Date + School + Grade group.

## 14. What if the Activity Date itself was wrong?

Do not simply add the learner on the correct date because the wrong-date row may remain saved. Follow the wrong-date correction instructions in the Full Guide. If the whole batch/date was wrong, ask the NIP/System Admin to remove the incorrect import first.

## 15. What if School or Grade was wrong?

Ask the NIP/System Admin before re-uploading. The dashboard protects the System Learner ID from being reassigned to a different school or grade.

## 16. What if the same System Learner ID was accidentally used for another learner?

Stop using that ID and ask the NIP/System Admin to correct the bad assignment before recording more follow-up activity.

## 17. Do we still need LRN as the matching key?

No. The workflow uses the System Learner ID as the stable matching identifier.

## 18. Should I put a learner's name or LRN in Remarks or Reason Details?

No. Do not place unnecessary identifying information in stored free-text fields.

## 19. What does Matched mean?

It means the RHU learner-record totals and the latest available VaccTrack extract agree.

## 20. What does Pending VaccTrack Verification mean?

The latest official VaccTrack extract has not yet caught up to the activity date. It is not automatically an encoding error.

## 21. What should I check when VaccTrack does not match?

Check Activity Date, School, Grade, vaccine status, duplicate/carry-over doses in follow-up rows, and whether the latest VaccTrack extract already includes that activity date.

## 22. I already uploaded the exact same correct file. Should I import it again?

No. If the dashboard says it is already up to date, continue to the next step.

## 23. What if the whole activity was encoded under the wrong date?

Ask NIP/System Admin to remove the incorrect import/batch in **Administration → Import Management**, then upload the corrected activity file. Do not keep both dates.
